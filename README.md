# Smart URL · Bibliographic identifiers

Adds an ISBN field type to the Smart URL catalogue. ISBN-10 and ISBN-13 values are checked and saved in their canonical form.

Install this directory at `mod/smarturl/metadata/type/identifier` in Moodle 4.5 or `public/mod/smarturl/metadata/type/identifier` in Moodle 5.3. Use the release that matches the Moodle version, and install Smart URL first.
